# Grade Prediction of Students Based on Socio-Economic Factors

## Project Overview
This project performs Exploratory Data Analysis (EDA) on student academic performance using socio-economic and educational factors.

The objective is to understand the factors associated with students' final grades and prepare the dataset for machine learning.

## Dataset
- 12,000 student records
- 29 original columns
- Academic, demographic and socio-economic information

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Understanding the Dataset
2. Data Cleaning
3. Outlier Detection
4. Pattern Identification
5. Relationship Analysis
6. Data Visualization
7. Machine Learning Data Preparation

## Key Findings
- Average final grade: approximately 66.94%.
- Average attendance: approximately 85.85%.
- Previous-year grades showed the strongest correlation with final grades among the selected academic variables.
- Study hours showed a weak positive correlation with final grades.

## Machine Learning Preparation
- Missing values handled
- Categorical variables encoded
- Input features and target selected
- Dataset split into 80% training and 20% testing data

## Project Status
EDA completed. Dataset prepared for machine learning. A prediction model has not yet been trained.
